# DevOps Project - Docker & Swarm



This repository contains the final project for the DevOps course, covering Docker Compose, Docker Swarm, and ELK Cluster.



## Project Structure

- `part1/`: Docker Compose (Keycloak, PostgreSQL, cURL, Nginx)

- `part2/`: Docker Swarm ELK Stack Simulation

- `part3/`: ELK Cluster (Hot/Warm/Cold) with HAProxy TLS



## How to Run

Refer to the `docker-compose.yml` and `elk-stack.yml` files in each directory.



## Notes

Due to network restrictions (sanctions) and hardware limitations (single VM), simulation images (nginx) were used for ELK services.
